Provable data erasure, run live in your browser

A complete, tamper-evident GDPR-Erasure lifecycle — encrypt → seal on-chain → retention → trigger → crypto-shred — executed end-to-end against this live node. No install, no clone. The same flow a regulated firm or AI company wires into production.

Honest scope (verified — Dead Drop §9): the chain does not byte-erase and personal data is never on-chain — only a 32-byte ciphertext commitment. Erasure is effected by destroying the decryption key (crypto-shred — an ICO/ENISA-recognised technique). The chain's job is the tamper-evident retention clock and the provable key-shred trigger. The key here is held in-browser as an HSM stand-in; production wires the same trigger to a real HSM/KMS.
