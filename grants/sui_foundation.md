# Sui Foundation Grant Application — EvaporChain

## Project Name
Decay-Native Move Language Extensions

## Description
EvaporChain extends the Move language with thermodynamic state decay — objects have energy that depletes over time. We've built a working prototype demonstrating that temporal validity can be a type-level property in Move-compatible systems. This research benefits the entire Move ecosystem.

## What We Built
- Move-compatible execution engine with decay semantics
- EvaporScript: a scripting language with lifecycle hooks (on_evaporate, on_grace, on_refresh) that demonstrates how Move could support temporal types
- 6 decay-native contract templates showing new application patterns
- 298 tests, live testnet

## How This Benefits the Sui/Move Ecosystem
- Demonstrates new Move language extension patterns (temporal types)
- Opens new application categories: expiring tokens, mortal NFTs, self-cleaning contracts
- Increases Move developer mindshare by showcasing innovative use cases

## Amount Requested: $30,000

## Deliverables
1. Published research on temporal type extensions for Move
2. Open-source EvaporScript implementation
3. Developer documentation and tutorials
4. Presentation at Move ecosystem events
